# Office 1.2.0 Collabora 集成验收

本版按独立插件流程发布 Release 和市场安装包，公开状态以远端 Release、市场目录及下载摘要为准。在宿主基线 da8fdc95 上增加 WOPI 服务和结构化 AI 文档接口，插件注册对应工具与设置；必须同步更新宿主，并具备 `office-collabora-v1` 能力。

- Node 注册测试和独立 ZIP 打包/CRC 检查通过，六个原生工具正确登记。
- 真实隔离 Collabora CODE 26.04.6.1、Aide 宿主和 Chromium 验证 DOCX 正文输入、XLSX B2 数值修改、PPTX 标题修改；WOPI 保存后从文件结构化读回核对。
- 文档可作为附件交给 Aide；选区文字可以回填任务输入框。未调用付费 AI 服务，原生 AI 工具调度另有宿主集成测试。
- 只读预览允许 AI 修改；活跃人工编辑拒绝 AI 覆盖；空闲且保存完成后允许 AI 修改并刷新编辑器。旧 hash 保存、只读来源写入、旧工作区/来源撤销/能力过期均有拒绝路径验证。
- Python 九项相关检查通过，包括整批失败不写入、原媒体成员保留、分页推进、字段拒绝和 Collabora 格式往返；宿主 Go、WOPI race 和文件路由检查通过。

64 MiB 输入和宿主 Office ZIP 解压/解析资源限制仍适用。结构化 AI 读写仅 DOCX/XLSX/PPTX；旧格式和 ODF 的网页操作以服务 discovery 为准，未做这些格式的往返验收。未验证企业订阅、生产容量、故障恢复或全部平台；窄屏检查仅确认 Aide 工具栏和 iframe 边界，文档仍按编辑器缩放和滚动查看。

Collabora 服务为独立第三方服务，主要 MPL 2.0；ZIP 本身只包含 MIT 插件适配代码、文档及测试。测试服务、日常 Aide 实例升级与公开发布是不同状态。
